# AppChain Roadmap

The AppChain is the endgame, not the first milestone.

1. Phase 1: Local Foundry MVP
2. Phase 2: Private EVM devnet
3. Phase 3: Avalanche L1 / Subnet-EVM prototype
4. Phase 4: Validator set design
5. Phase 5: Bridge design
6. Phase 6: Oracle and reserve attestation integration
7. Phase 7: Legal/custody framework
8. Phase 8: Public testnet stress competition
9. Phase 9: Capped mainnet beta

Correct order:

1. Monetary logic first
2. Stress tests second
3. AppChain infrastructure third
4. Real reserves last

No validator or bridge work belongs in the v0 repository until the protocol survives local solvency and redemption stress tests.
